# Домашнє завдання 2.1 — Blink на Embedded C++ (ESP32)

Переписаний «класичний Arduino blink» у стилі Embedded C++: неблокуючий
superloop, класи замість глобального коду, конфігурація без «магічних чисел»
та керування світлодіодом через апаратне переривання від кнопки.

## Що реалізовано

**1. Blink на Embedded C++**
- Стан світлодіода через `enum class LedState { LED_OFF, LED_ON }`.
- Номер піна й інтервал блимання — `constexpr` (без `delay()`).
- Неблокуючий superloop на `millis()`.
- Клас `LedStateMachine` (з методами `init()` / `update()`) інкапсулює логіку.

**2. Конфігурація через `static constexpr`**
- Клас `Config` збирає всі налаштування (піни, інтервали, debounce) як
  `static constexpr` — усі «магічні числа» винесені з коду.

**3. Вимір часу ітерації superloop**
- Тривалість однієї ітерації `loop()` міряється через `micros()`.
- Результат виводиться в Serial Monitor кожні 1000 ітерацій.

**4. Кнопка через апаратне переривання**
- Кнопка на GPIO з `attachInterrupt(...)`.
- Прапорець `volatile bool buttonPressed` сигналізує про натиск.
- **ISR мінімальна** — лише виставляє прапорець і запалює червоний
  світлодіод-індикатор (`digitalWrite`); ніякого `Serial` всередині ISR.
- Уся логіка — в `loop()`: при натисканні кнопки режим світлодіода
  перемикається по колу **блимання → постійно увімкнено → постійно вимкнено →
  блимання**. Додано програмний антидребезг (`Config::DEBOUNCE_MS`).

## Запуск

```bash
pio run -e task_2_1 -t upload
pio device monitor -b 115200
```
