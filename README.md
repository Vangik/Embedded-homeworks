# Модуль 3.7 — Керування сервоприводом за допомогою енкодера

Сервопривід SG90 керується інкрементним енкодером:

- **1 клік енкодера** повертає вал на фіксований кут у відповідному напрямку.
- **Короткий натиск кнопки** зменшує крок удвічі (10° → 5°), повторний — повертає назад.
- На **крайніх положеннях** (0° / 180°) при спробі крутити далі лунає короткий сигнал баззера.
- **Довге утримання кнопки** (≥2 с) повертає вал у центр (90°).

**Платформа:** ESP32 (DevKit) · **Фреймворк:** ESP-IDF

| Компонент | GPIO |
|-----------|------|
| Сервопривід SG90 (PWM 50 Гц) | GPIO5 |
| Енкодер CLK (A) | GPIO19 |
| Енкодер DT (B) | GPIO21 |
| Кнопка енкодера (SW) | GPIO18 |
| Баззер | GPIO15 |

Крок: `SERVO_STEP1 = 10°`, `SERVO_STEP2 = 5°`. Glitch-фільтр PCNT: `1000 нс`.
