# Модуль 3.4. Зворотна дія: перетворюємо число на напругу (DAC, PWM)

## Опис завдання

**Завдання, зробити неблокуючий аудіо-плеєр для зумера та окремо програти мелодію.**

Реалізовано програвач мелодії на пасивному зумері через PWM (периферія LEDC),
який:
- генерує тон заданої частоти через ШІМ (PWM / LEDC);
- працює на фіксованому часовому тіку **50 мс**;
- **не блокує** виконання програми;
- **не використовує** окрему FreeRTOS-задачу та `vTaskDelay` — час рахується
  через апаратний `esp_timer` з періодичним колбеком.

## Апаратна частина

| Елемент | Пін ESP32 |
|---|---|
| Пасивний зумер (+) | GPIO4 |
| Зумер (−) | GND |

## Мелодія

Використано **власну оригінальну мелодію** (не захищену авторським правом),
описану масивом `note_t k_theme[]`. Кожна нота — пара `{частота_Гц, тривалість_мс}`,
`REST` (частота 0) = пауза.
