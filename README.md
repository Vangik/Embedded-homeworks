# Superloop: три незалежні LED без блокування

Домашнє завдання на неблокуючу багатозадачність у `loop()`.
Три світлодіоди блимають з різними інтервалами одночасно, кожен незалежно,
без `delay()` та без очікування через `while()` — тільки на `millis()`.

## Що робить

| LED  | Пін GPIO | Інтервал |
|------|----------|----------|
| LED1 | 2       | 200 мс   |
| LED2 | 17       | 500 мс   |
| LED3 | 18       | 1000 мс  |

## Як це працює

Кожен світлодіод має власну мітку часу (`prev`). На кожній ітерації `loop()`
для кожного LED перевіряється, чи минув його інтервал:

```cpp
if (now - prev >= interval) {
    prev = now;
    digitalWrite(pin, !digitalRead(pin));
}
```

Три окремі `if` (не `else if`) — тому на одній ітерації можуть перемкнутись
хоч усі три одразу, не заважаючи один одному. Порівняння `>=` (а не `==`)
робить логіку стійкою до затримок у циклі та до переповнення `millis()`.

## Обмеження завдання

- ❌ Без `delay()`
- ❌ Без `while()` для очікування часу
- ✅ Тільки `millis()`
