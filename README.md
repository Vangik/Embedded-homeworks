# Вимірювання часу спрацювання реле на ESP32

Вимірювання механічної затримки увімкнення та вимкнення реле за допомогою ESP32,
переривань (`attachInterrupt`) і таймера `micros()`.

https://github.com/user-attachments/assets/fe42eb6d-559f-4612-a75e-5c0a53e5535e


## Завдання

Виміряти механічну затримку спрацювання реле:

- один пін GPIO керує обмоткою реле (через модуль);
- інший пін GPIO зчитує стан «сухого» контакту реле (`INPUT_PULLUP`);
- час вимірюється через `micros()` та переривання (`attachInterrupt`);
- враховано механічний брязкіт контактів;
- проведено 10 вимірювань, результати виводяться в Serial Monitor,
  розраховано середній час увімкнення/вимкнення.

## Обладнання

- ESP32 (DevKit)
- Модуль реле (з керуванням по IN, живлення VCC/GND)
- З'єднувальні дроти

### Як це працює

Сухий контакт реле — це механічний вимикач без власної напруги.
COM з'єднаний із GND, NO читається піном з внутрішньою підтяжкою:

- реле **вимкнене** → NO розімкнений → підтяжка тримає пін у `HIGH` (1);
- реле **увімкнене** → NO замикається на GND → пін падає в `LOW` (0).

## Принцип вимірювання

1. Записуємо час `micros()` у момент подачі команди на обмотку.
2. Переривання (`CHANGE`) фіксує час першого фронту на сухому контакті.
3. Затримка спрацювання = час фронту − час команди.

### Обробка брязкоту

Механічний контакт при спрацюванні кілька разів клацає (брязкіт).
Для вимірювання *часу спрацювання* фіксується **тільки перший фронт** —
наступні фронти брязкоту ігноруються прапорцем `edgeCaptured`.
