# Модуль 3.5 — Керування сервоприводом за допомогою PWM

Потенціометр керує положенням валу сервоприводу в пропорції **1:1**.
Розбіжність діапазонів обрізається (використовується лише спільна частина
0…180°), а кут відхилення від крайнього лівого положення логується в консолі.

**Платформа:** ESP32 (DevKit) · **Фреймворк:** ESP-IDF
**Сервопривід (SG90):** GPIO18 (PWM 50 Гц)
**Потенціометр:** GPIO4 (ADC)
