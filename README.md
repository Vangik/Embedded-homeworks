# Керування витяжним вентилятором, за допомогою таймера  (ESP32, ESP-IDF)

Модуль 2.5 — керування витяжним вентилятором: **кожну годину вмикається на 15 хвилин**, потім автоматично вимикається. Цикл повторюється безкінечно.

https://github.com/user-attachments/assets/ad2dfb74-6ea3-4140-aba7-052647edba5c

Уся логіка живе в **апаратному таймері (GPTimer)** — реле перемикається в перериванні, `app_main` у керуванні не бере участі. `delay()` не використовується.

## Як працює

Один GPTimer з **двома періодами**, які він перемикає сам у callback:

```
старт: реле OFF, період = 1 год
 └→ alarm (через 1 год)  → реле ON,  наступний період = 15 хв
     └→ alarm (через 15 хв) → реле OFF, наступний період = 1 год
         └→ і так по колу, без loop
```

При кожному спрацюванні ISR: перемикає реле, ставить наступний період через `gptimer_set_alarm_action` (без `delay`, без відліку в циклі).

`app_main` лише логуе стан і годує watchdog.

## Відповідність умовам

| Вимога | Як виконано |
|---|---|
| Вмикання щогодини на 15 хв | два періоди таймера (1 год / 15 хв) |
| Таймери працюють незалежно від циклу | реле керується в ISR таймера |
| Без `delay()` | час відлічує GPTimer |
| Цикл повторюється без `loop()` | автоперемикання періодів у callback |
| Час/період — змінні або макроси | `FAN_ALARM_PERIOD`, `FAN_WORK_TIME` |

## Підключення

| Компонент | GPIO | Примітка |
|---|---|---|
| Реле (обмотка) | 23 | модуль з транзистором + flyback-діодом |
| LED «працює» | 19 | горить, поки вентилятор увімкнено |
| LED «очікує» | 5 | горить у паузі між циклами |

Вентилятор = двигун через реле (реле комутує силове коло).


- Реле комутує **5 В** — не торкайся силового кола під напругою.
