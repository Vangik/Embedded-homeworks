# Розумний світлофор (ESP32, ESP-IDF)

Модуль 2 Проєкт — керування світлофором за ПДР України з нічним режимом, пішохідною кнопкою та звуковим сигналом для незрячих.

https://github.com/user-attachments/assets/0a9d56cd-ba08-4817-9902-7082beff050d

Реалізовано на **скінченному автоматі (FSM)** без жодного `delay()` — усі затримки рахуються через `esp_timer`, тому кнопка й датчик реагують миттєво.

## Можливості

- **Світлофор для машин** — повний цикл ПДР: зелений → зелений миготливий → жовтий → червоний → червоний+жовтий → …
- **Світлофор для пішоходів** — зелений лише коли машинам горить червоний.
- **Кнопка-запит пішохода** — натиск безпечно скорочує зелений машинам і швидше дає перехід.
- **Фоторезистор (LDR)** — вимірює освітленість; у темряві світлофор переходить у **жовтий миготливий** (нерегульоване перехрестя).
- **Buzzer** — пікає, поки пішоходам горить зелений (звуковий орієнтир для незрячих).

## Як це працює

### 1. Світлофор для машин (FSM)
Кожен стан описаний у таблиці `TABLE[]` (тривалість + які лампи + чи мигає). Головний цикл рахує, скільки триває поточний стан, і коли час вийшов — перемикає на наступний по колу. Мигання дає формула `(now_ms / BLINK_HALF_MS) % 2`.

### 2. Світлофор для пішоходів
Не має власних станів — виводиться зі стану машин: зелений пішоходам = машинам червоний і не горить жовтий.

### 3. Кнопка пішохода (переривання)
Натиск генерує апаратне переривання. ISR **лише ставить прапорець** — уся логіка в головному циклі. Цикл бачить запит і, якщо зараз їде зелений, скорочує його, безпечно проводячи цикл через жовтий до червоного (де пішоходи переходять).

### 4. Фоторезистор → день/ніч
Раз на 100 мс читається ADC, з напруги обчислюється опір LDR, а з нього — освітленість у lux (крива GL5528). Рішення день/ніч має **гістерезис** (два пороги), щоб на межі світло не блимало. У ночі — жовтий миготливий.

### 5. Buzzer (звук для незрячих)
Пасивний buzzer керується апаратним таймером `GPTimer`: його переривання смикає пін і створює квадратну хвилю (тон). Поки пішоходам зелений, тон вмикається ритмічними піками.
